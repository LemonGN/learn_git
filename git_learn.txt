无法push的解决方案： 
    遇到的问题

    连不上：Git 默认不读取电脑的系统代理，直连 GitHub 被网络阻断（报错 timeout/reset）。

    握手失败：给 Git 配了代理后，Git 默认调用的 Windows 系统加密组件（schannel）无法兼容代理环境，导致安全校验失败（报错 schannel failed）。

    解决逻辑（仅对 Git 生效，不影响其他软件）

    指定专属通道：让 Git 强制走你代理软件的本地端口（SOCKS5 协议），并且让域名解析也走代理。

    更换加密组件：让 Git 放弃 Windows 自带的安全组件，改用 Git 自带的 OpenSSL 组件，完美兼容代理环境。

    永久生效与影响范围

    永久生效：这两个设置被写进了 Git 的全局配置文件中，以后每次使用 Git 都会自动生效。

    零副作用：这些配置是 Git 私有的，绝不会影响浏览器、微信或其他软件的正常上网。

    日常注意事项

    前提：使用 Git 时，你的代理软件必须处于开启状态，且端口不能变。

    撤销：如果以后不想用代理了，只需将 Git 的相关代理配置清除即可恢复直连。
